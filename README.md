# AuraCuna – Cuna Inteligente IoT

AuraCuna es un proyecto de **Internet of Things (IoT)** cuyo objetivo es desarrollar una cuna inteligente capaz de monitorizar el estado del bebé y su entorno en tiempo real mediante sensores y una aplicación móvil.

El sistema permite a los padres **supervisar, recibir alertas y controlar ciertas funciones de la cuna** desde una app, mejorando la seguridad y el bienestar del bebé.

---

## Funcionalidades principales

La cuna inteligente integra varios sensores que monitorizan continuamente el estado del bebé y las condiciones del entorno.
El sistema se comunica con una **aplicación móvil**, que permite visualizar los datos en tiempo real y gestionar las funciones del dispositivo. 
El sistema ofrece varias funciones para mejorar la supervisión del bebé:

* Monitorización en tiempo real del entorno
* Notificaciones cuando el bebé entra o sale de la cuna
* Reproducción de sonidos relajantes
* Control remoto de iluminación
* Mecimiento automático de la cuna
* Visualización de datos históricos y estadísticas

Además, el sistema puede enviar alertas si la **temperatura o la actividad del bebé se encuentran fuera de los rangos normales**. 

---

## Lenguajes y tecnologías

Este proyecto utiliza distintas tecnologías orientadas al desarrollo IoT:

**Lenguajes**

* Java (aplicación Android) 
* Arduino (C)

**Tecnologías**

* Android Studio
* Firebase
* Sensores IoT (movimiento, presión y temperatura)
* Comunicación entre dispositivo y aplicación móvil

---

## Estructura del sistema

El sistema está compuesto por tres partes principales:

1. **Cuna inteligente**

   * Sensores que monitorizan el estado del bebé
   * Actuadores como luces y altavoces

2. **Plataforma IoT**

   * Comunicación entre la cuna y la aplicación

3. **Aplicación móvil**

   * Visualización de datos en tiempo real
   * Control remoto de funciones
